# 앱 UI 리디자인 최종 지시서

앱 UI 리디자인 최종 지시서야. 지금까지 미리보기에서 시도한 글래스모피즘·컬러풀 안은 전부 폐기하고 이걸 기준으로 다시 만들어줘.
먼저 이 지시서 전체를 docs/ui-redesign-spec.md 로 저장하고, 팀원 모두 이 파일을 기준으로 작업해. 레퍼런스를 재해석하지 말고 아래 수치·규칙을 그대로 따를 것.

━━━━━━━━━━━━━━━━━━━━
1. 디자인 방향
━━━━━━━━━━━━━━━━━━━━
- 깔끔한 뉴트럴 UI (첨부 레퍼런스 2장). 글래스모피즘 아님.
- 원칙: 상자 겹침은 최대 1겹 / 포인트 색은 1개만 / 구분은 여백·글자 크기·옅은 면으로

[AI 티 금지 목록]
- 파스텔 여러 색, 그라디언트, 글로우, 반짝이, 그라디언트 테두리
- 이모지 아이콘
- 상자 안에 상자 안에 상자
- 모든 카드 같은 크기·같은 모서리로 나열, 모든 것 가운데 정렬

━━━━━━━━━━━━━━━━━━━━
2. 스타일 수치
━━━━━━━━━━━━━━━━━━━━
[라이트]
- 창 바탕 #F4F4F4 / 패널 #FFFFFF / 패널 안 항목 면 #F4F4F4 / 세그먼트 트랙 #EFEFEF
- 테두리 1px #ECECEC / 본문 글자 #111111 / 보조 글자 #8A8A8A
[다크]
- 창 바탕 #0F0F10 / 패널 #18181A / 항목 면 #222225 / 트랙 #26262A
- 테두리 #2A2A2E / 본문 #F2F2F2 / 보조 #8E8E93
[공통]
- 모서리: 패널 16px, 내부 요소 10px, 알약 버튼 999px
- 그림자 없음. 떠 있는 팝오버·모달·토스트만 아주 옅은 그림자, 토스트만 blur 12px 허용
- 포인트 색 1개(기본 파랑 계열 하나), 쓰는 곳: 토글 켜짐, 슬라이더 채움, 선택 표시, 링크 정도
- 주요 버튼은 화면당 1개만 검정(#111, 다크에선 흰색) 채움, 나머지는 회색 면 버튼

[글자]
- UI 폰트 Pretendard (앱 안에 포함, 오프라인 동작)
- 박다현체는 로고·앱 이름에만 (앱 안에 포함, CDN 제거)
- 큰 제목 26~28px 굵게 / 소제목 13~14px 굵게 / 본문 13~14px / 라벨 12px 보조색

[아이콘]
- 이모지 전부 제거 → lucide 계열 얇은 선 아이콘(1.5px), 단색
- 동물 선택에는 이모지 대신 실제 버디 이미지

[다크/라이트 전환]
- html의 data-theme 기준. 버튼 순환: 라이트 → 다크 → 시스템. 버튼이 시스템 설정보다 우선. 선택은 저장해서 재시작 후 유지

━━━━━━━━━━━━━━━━━━━━
3. 화면 구조 (홈 한 화면에서 거의 다 끝내기)
━━━━━━━━━━━━━━━━━━━━
[왼쪽 메뉴]
- 아이콘만 있는 얇은 세로 메뉴(흰 알약 안 아이콘): 홈 / 알람 / 사용 방법, 맨 아래 앱 종료
- 마우스 올리면 이름 툴팁, 선택된 아이콘만 포인트 색 면

[홈]
- 맨 위: 큰 제목 "내 버디" + 보조 설명 한 줄, 오른쪽 위 라이트/다크 전환
- 메인 카드:
  · 오른쪽: 버디 실시간 미리보기 크게(#F4F4F4 면, 모서리 16px). 아래 버튼 2개 "동물 바꾸기" / "사진 올리기"
  · 왼쪽 위: 현재 버디 이름 + 한 줄 요약(예: Buddy 모드 · 중간 크기)
  · 왼쪽 아래: 설정 칩 그리드 — 칩은 #F4F4F4 면, 위에 작은 라벨, 아래 굵은 현재 값
    모드 / 크기 / 활동 구역(4분할·모니터 선택 포함) / 표시 / 움직임 속도 / 야르 타임 / 졸림 방지 / 모양(원형·사각형)
  · 칩을 누르면 칩 바로 아래 작은 팝오버에서 변경(세그먼트·슬라이더·토글)
- 아래 카드 2개: 점심 알림 / 퇴근 알림 — 시간, 켜짐 토글, 미리 알림 분을 카드 안에서 바로 변경
- "동물 바꾸기" = 모달 안에 동물 타일 그리드(#F4F4F4 타일, 선택된 것만 진한 2px 테두리)
- "사진 올리기" = 기존 자르기 창 (같은 스타일로)

[알람]
- 일반 알람 최대 5개 목록 + 추가 + 알람 테스트 버튼
- 목록은 줄 단위, 줄 사이 1px 구분선

[사용 방법]
- 기존 내용 유지, 같은 스타일

[컨트롤 공통]
- 세그먼트(탭·소중대·원형/사각형): 회색 트랙 안에 선택된 것만 흰 알약
- 섹션 사이 간격 32~40px, 섹션 안 요소 간격 12px

━━━━━━━━━━━━━━━━━━━━
4. 그 외 화면
━━━━━━━━━━━━━━━━━━━━
- 사진 자르기 창, 점심·퇴근·알람·야르 전체화면 알림, 미리 알림 토스트 모두 같은 규칙
- 알림·토스트는 흰 면(다크는 #18181A) + 옅은 그림자 + blur 12px, 글자 대비 4.5:1 이상

━━━━━━━━━━━━━━━━━━━━
5. 동작 변경
━━━━━━━━━━━━━━━━━━━━
- 저장 버튼 제거, 값을 바꾸면 즉시 적용(기존 저장 로직 + syncSettings 호출, 300ms 디바운스)
- 기존 IPC·설정 키는 그대로
- 기존 기능은 하나도 빠짐없이 홈 칩·카드·모달·알람·사용 방법 중 어딘가로 옮길 것

━━━━━━━━━━━━━━━━━━━━
6. 작업 방식
━━━━━━━━━━━━━━━━━━━━
- 지금 브랜치에서 계속. push는 나한테 먼저 물어보기
- 1단계: design-preview.html에 새 안을 만들고 이전 안들과 전환 버튼으로 비교. 내가 OK하면
- 2단계: 실제 앱 코드에 적용, 기능별로 커밋
- 한글·이모지 포함 파일은 UTF-8 유지, 수정 후 깨짐 확인
- 애니메이션(팝오버 열림, 화면 전환, 토스트 등장)은 emil-design-eng 기준, 짧고 과하지 않게. 움직임 줄이기 설정 존중

[팀 역할]
- ui-designer: 이 지시서 기준으로 미리보기 제작, hallmark audit으로 AI 티 점검
- frontend-dev: 2단계 실제 구현
- code-reviewer: 기능 누락·IPC·즉시 저장 동작 검토
- qa-tester: npm run build, 라이트/다크·창 크기별 확인

[마지막에 보여줄 것]
1. 기존 기능 → 새 위치 대응표 (빠진 기능 없는지)
2. 내가 직접 눌러볼 것 목록

━━━━━━━━━━━━━━━━━━━━
추가 결정 (지시서 이후)
━━━━━━━━━━━━━━━━━━━━
- Twemoji 이미지를 앱 안에 포함(오프라인 동작). 앱에서 실제로 쓰는 것만 골라서 넣는다. CDN(jsdelivr) 참조는 제거.
- 사용 방법 화면 맨 아래에 출처 표기: "버디 이미지: Twemoji © Twitter, Inc. and other contributors · CC BY 4.0" (CC BY 4.0 → https://creativecommons.org/licenses/by/4.0/ 링크)
- 이모지 금지는 버튼·메뉴·라벨 "아이콘"에만 적용. 전체화면 알림의 이모지 버스트 연출(점심: 양옆 음식 15종 / 퇴근: 아래에서 솟는 15종 / 알람: 양옆 ⏰🔔 / 야르: 위에서 쏟아지는 50종 + 화면 살짝 어둡게)은 기존 앱 그대로 유지(종류·개수·크기·속도 동일).
- 야르~ 타임 전체화면은 카드(팝업) 없이 이모지만 쏟아진다(기존 앱과 같음).
- 펫 위 미리 알림 토스트는 미리보기 모양 그대로.

[미리보기 OK 후 결정 — 2단계 기준]
1. 보조 글자색: 라이트 #6B6B6B (흰 면 5.3:1). 다크 보조색도 패널(#18181A)·항목 면(#222225) 위 대비 4.5:1 이상이 되도록 정한다(#8E8E93이 부족하면 더 밝게).
2. 점심·퇴근 알림 키 분리: 켜짐 토글과 미리 알림 분을 점심·퇴근 따로 둔다(예: lunchEnabled / leaveEnabled, lunchPreAlertMinutes / leavePreAlertMinutes). 기존 breakTimeEnabled·preAlertMinutes 값을 새 두 키에 복사하는 마이그레이션을 추가한다(한 번만, 기존 사용자 설정 보존). 메인 프로세스 알림 로직도 새 키를 쓰게 한다.
3. 점심·퇴근 시각은 홈 카드에서 바로 변경. 출근·퇴근(근무) 시각처럼 자주 안 바꾸는 값만 알람 화면 "근무 시간" 카드에.
4. 설정 칩의 ⌄ 화살표 제거. 마우스를 올리면 칩 면이 살짝 진해지는 것으로만 클릭 가능함을 표시.
5. 시간 표기 통일: "오후 6:00" 형식(앞자리 0 없음). 설명 문구·알림 카드 시각도 같은 형식. (입력 컨트롤 자체는 type=time 유지 가능, 표시 문구 기준)
6. 홈 실시간 미리보기 속 버디를 미리보기 대비 1.5배 크기로.
7. 실제 설정창 크기 900×700에서 홈이 스크롤 없이 다 보이게. 안 되면 하단 카드 영역만 스크롤. 최소 크기 700×580에서도 레이아웃이 깨지지 않게(창 minWidth/minHeight 설정 포함).
8. 전체화면 알림(점심·퇴근·알람)은 "신나는 순간"이다. 깔끔한 흰 카드(다크 #18181A)는 유지하되 축하 느낌을 살린다:
   - 기존 이모지 폭발 애니메이션 그대로
   - 카드 안에 현재 선택한 버디 이미지(커스텀 사진이면 그 사진)를 크게 넣고, 버디가 살짝 통통 튀며 등장
   - 카드 등장은 emil-design-eng 기준으로 짧고 경쾌하게(UI 규칙과 달리 약한 오버슈트 허용)
   - 설정창의 절제된 규칙(포인트 색 1개 등)은 알림 화면에는 느슨하게 적용해도 된다
   - 야르~ 타임은 위 결정대로 카드 없이 이모지만
9. 전체화면 알림 카드의 시각도 "오후 6:00" 형식.

## 인트로·처음 안내 예외 (2026-10-21 결정)
위의 "AI 티 금지 목록"(그라디언트, 글로우, 반짝이)과 "완전 플랫" 규칙은 설정창 본문과 앱 아이콘·로고 기준이다. 아래는 **인트로 화면 안에서만** 쓰는 예외다.
- 인트로 하트의 입체감(3D 느낌): 안쪽 방사 그라데이션(부푼 느낌), 왼쪽 위 반사광, 아래쪽 림라이트, 노이즈, 눈 안쪽 광택, 마우스 방향 기울임(최대 6도). 실제 3D 렌더링(three.js, WebGL)은 쓰지 않고 SVG 그라데이션·필터와 CSS만 쓴다.
- 입구 버튼("처음 왔어요" / "오늘도 함께해요") 호버·포커스·클릭 연출: 빛 한 번 쓸기, 하트 두근, 4점 별 스파클(단색 플랫). 움직임 줄이기에서는 끄고 버튼 색 변화만 둔다.
- 앱 아이콘·로고·트레이 아이콘은 이 예외와 무관하다(기존 규칙 그대로).
- 처음 안내(온보딩) 3단계 화면은 설정창과 같은 뉴트럴 규칙(상자 한 겹, 포인트 색 하나)을 따른다. 이모지 없음, 해요체.
