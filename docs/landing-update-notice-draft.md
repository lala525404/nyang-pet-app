# 랜딩 안내 문구 초안 — 업데이트가 들어간 첫 버전 (기존 사용자용)

> 초안입니다. 랜딩 repo는 수정하지 않았고, 아래 문구를 복사해서 쓰면 됩니다. 버전 번호(`X.Y.Z`)는 업데이터가 처음 들어가는 버전(예: 1.4.0)으로 바꿔 주세요.

## 다운로드 영역 (Windows)

**이제 설치해서 쓰고, 새 버전은 앱이 알려 드려요**

설치 파일을 한 번만 받아 실행하면, 그다음부터는 새 버전이 나올 때 앱이 "업데이트할까요?"라고 물어봐요.
버튼 한 번이면 끝이고, 작업 표시줄에 고정해 둔 것도 그대로 유지돼요.

- 관리자 권한이 필요 없어요. 내 계정에만 설치돼요.
- 바탕화면과 시작 메뉴에 바로가기가 만들어져요.
- 설정·알람·사진은 그대로 이어져요.

[Windows용 설치 파일 받기 (choeae-app-Setup-X.Y.Z.exe)]

> Windows가 "PC를 보호했습니다"라고 알려 줄 수 있어요. 이럴 땐 **추가 정보 → 실행**을 눌러 주세요. (아직 Windows 코드 서명 인증서가 없어서 나오는 안내예요.)

## 기존에 포터블 파일(choeae-app-1.x.x.exe)을 쓰던 분께

1. 위 **설치 파일**을 받아 실행해 주세요. (이전 버전을 먼저 종료하지 않아도 되지만, 두 개가 동시에 떠 있지 않게 설치가 끝나면 이전 창은 닫아 주세요.)
2. 설치가 끝나면 앱이 자동으로 열려요. **알람 설정과 사진은 그대로예요.** 다시 설정하지 않아도 돼요.
3. 예전에 받아 둔 **포터블 exe 파일은 지워도 돼요.** 작업 표시줄에 고정해 두셨다면, 새로 설치된 앱을 실행한 뒤 다시 한 번만 고정해 주세요.
4. 이후에는 새 파일을 받을 필요가 없어요. 새 버전이 나오면 앱이 알려 드려요.

## 다운로드 영역 (macOS)

**macOS는 설치 파일(dmg)을 열어 앱을 "응용 프로그램" 폴더로 옮겨 주세요**

그래야 앞으로 새 버전이 나올 때 앱이 스스로 업데이트할 수 있어요. dmg 안에서 바로 실행하거나 다운로드 폴더에서 쓰면 자동 업데이트가 되지 않아요.

[macOS용(Apple 실리콘) 받기 (choeae-app-X.Y.Z-arm64.dmg)]

## 기존 맥 사용자께

앱을 **응용 프로그램 폴더**에 옮겨서 실행해 주세요. 다운로드 폴더나 dmg 안에서 실행하고 있다면 이번에 한 번만 옮겨 주시면 돼요. 알람·설정은 그대로 이어져요.

## 참고: 개인정보 처리방침에 반영할 내용 (정리만, 수정하지 않음)

업데이트 확인은 앱이 GitHub(`github.com`, 파일 다운로드는 `objects.githubusercontent.com`)에 접속하는 기능이에요. 처리방침에 아래 내용을 추가하는 것을 권장해요.

- 앱은 시작 10초 뒤와 6시간마다 GitHub의 릴리스 정보 파일(`latest.yml` 등)을 조회해 새 버전이 있는지 확인해요. 설정창의 "업데이트 확인" 버튼으로도 확인할 수 있어요.
- 이 과정에서 서비스(GitHub)가 접속 정보(IP 주소, 사용 중인 앱 이름·버전·운영체제·CPU 구조가 담긴 요청 헤더)를 일반적인 웹 접속 기록으로 처리할 수 있어요. 앱이 알람·설정·사진 등 사용자 데이터를 업데이트 확인에 실어 보내지는 않아요.
- 새 버전을 받는 것은 사용자가 "지금 업데이트"를 선택했을 때만 시작돼요(자동으로 내려받지 않아요).
- 업데이트 확인을 끄는 설정은 아직 없어요(필요하면 추가 검토).
